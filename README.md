# 露出計（単体HTML版）

フィルム撮影のための露出計アプリです。`index.html` 1ファイルで動きます（アイコン用に `icon.png` を一緒に置きます）。

## GitHub Pagesでの公開手順
1. GitHubで新しいリポジトリ「exposure-meter」を作ります
2. `index.html` と `icon.png` をアップロードします
3. リポジトリの Settings → Pages で、公開するブランチ（main）を選びます
4. 数分待つと公開されます

公開URL： https://jkj7vv2nd7-lang.github.io/exposure-meter/

iPhoneのSafariで開いて「ホーム画面に追加」すると、専用アイコンでアプリのように使えます。

## データについて
- 設定・露出記録・カスタムフィルムは、その端末のブラウザの中にだけ保存されます。サーバーには送られません
- Museライブラリ版とはデータは共有されません（単体版は空の状態から始まります）

## 注意
- カメラスポットチェックは、ブラウザと端末によっては使えないことがあります。その場合もシーン選択で全ての計算が使えます
- スポットチェックの値は目安であり、絶対EVの断定には使えません
